⚡ Potenciação & Radiciação

  • • aᵐ · aⁿ = aᵐ⁺ⁿ
  • • aᵐ / aⁿ = aᵐ⁻ⁿ (a ≠ 0)
  • • (aᵐ)ⁿ = aᵐ·ⁿ
  • • a⁻ⁿ = 1 / aⁿ
  • • a^(m/n) = ⁿ√(aᵐ)
  • • √(a·b) = √a · √b
  • • Prod. Notável: (a±b)² = a² ± 2ab + b²
  • • Dif. Quadrados: a² - b² = (a+b)(a-b)

📊 Razão, Proporção & %

  • • Escala: E = d(desenho) / D(real)
  • • Área na Escala: A_des / A_real = E²
  • • Volume na Escala: V_des / V_real = E³
  • • Aumento de i%: V_f = V_0 · (1 + i)
  • • Desconto de i%: V_f = V_0 · (1 - i)
  • • Juros Simples: J = C · i · t
  • • Juros Compostos: M = C · (1 + i)ᵗ

🚀 Grandezas, Notação & Vetores

  • • Notação: N = a · 10ⁿ (1 ≤ |a| < 10)
  • • Vel.: ÷ 3,6 (km/h → m/s) | × 3,6 (inv)
  • • 1 m³ = 1.000 L | 1 cm³ = 1 mL
  • • Vetor Resultante (90°): R = √(A² + B²)
  • • Decomposição: Fx = F·cosθ | Fy = F·senθ
  • • MRU: S = S₀ + v·t
  • • MRUV: v = v₀ + a·t | v² = v₀² + 2aΔS

🧪 Química Básica & Mol

  • • Átomo: Z = p | A = p + n | Íon: e⁻ = Z - q
  • • Tabela: Raio ↑ (← e ↓) | EN ↑ (→ e ↑)
  • • Ligações: Met+Amet (Iônica) | Amet+Amet (Cov)
  • • Separação: Destilação (PE) | Filtração (Sol/Líq)
